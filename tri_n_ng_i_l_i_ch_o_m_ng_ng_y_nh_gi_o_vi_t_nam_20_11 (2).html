Hướng Dẫn Đưa Website Lên Internet Để Quét QR

  1. Cách 1 – GitHub Pages / Netlify Drop (Miễn phí, 30 giây): Truy cập app.netlify.com/drop hoặc tạo kho lưu trữ GitHub Pages, kéo thả file index.html vào. Bạn sẽ nhận được đường dẫn công khai dạng https://tri-an-20-11.netlify.app.
  2. Cách 2 – Chia sẻ tức thì không cần máy chủ (Gói dữ liệu vào URL): Sau khi nhấn "Lưu & Xuất Bản", hệ thống tự động nén dữ liệu tiêu đề, lời chúc, màu sắc vào tham số ?mode=presentation&data=... trong mã QR để điện thoại khác quét là thấy ngay nội dung bạn vừa sửa!
  3. Cách 3 – Đồng bộ ảnh/video dung lượng lớn qua Firebase / Supabase: Nếu tải lên nhiều ảnh gốc độ phân giải cao, hãy tạo bảng publications trên Supabase hoặc Firebase Realtime Database (chế độ RLS: cho phép SELECT công khai cho ?mode=presentation, chỉ cho phép INSERT/UPDATE khi có JWT Admin Token).

Đổi Mật Khẩu Quản Trị & Phân Quyền Máy Chủ

Lưu ý bảo mật: Với kiến trúc 1 file HTML tĩnh chạy độc lập trên trình duyệt, việc khóa giao diện bằng ?mode=presentation và băm mật khẩu SHA-256 giúp ngăn người xem thông thường chỉnh sửa, nhưng không thay thế hoàn toàn xác thực phía máy chủ (Server-side Auth). Khi triển khai thực tế với cơ sở dữ liệu chung, cần bật phân quyền API ở máy chủ.
